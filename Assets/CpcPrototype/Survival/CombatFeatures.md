# 전투 기능

현재 적용 씬: `Assets/Scenes/KayKit_DepthSurvival.unity`.

- 좌클릭: 라이플 총격 (몸 10 / 머리 20). 기본 장탄 31발(30발 탄창+약실), 예비 탄약 90발이며 Inspector의 `SurvivalPlayer`에서 조절한다. R키로 재장전하고 탄창이 비면 자동 재장전한다. 빈 탄창에서 최대 30발, 탄창에 탄이 남았으면 최대 31발까지 채운다. 우측 하단에 현재 장탄/남은 총 탄약을 표시하고 탄약이 완전히 소진되면 중앙에 2초간 경고한다. 우클릭은 가로등 전구 그래플로 변경되었으며, 근접공격 (피해 20, 재사용 .6초)은 `SurvivalPlayer.Melee()`에 보존합니다.
- 가로등 전구 우클릭으로 후킹하면 플레이어와 전구를 잇는 수직 평면에서 스윙해 전구 반대편의 초기 거리 절반 지점에 도착한다. 최대 후킹 거리는 `Player Grapple Action`의 `Max Hook Distance`에서 설정한다. 그래플 도착 후 기본 5초 동안 스나이퍼·슬로모션을 사용한다. 우클릭을 유지해 조준하고 좌클릭으로 사격한다. 시간이 끝나면 기본 시점과 라이플로 복귀한다. [그래플/스나이퍼 설정 및 검증](../../../Tools/GrappleSniper/README.md).
- 가운데 마우스: 기존 3인칭 조준. Q: CPC 돌진, E: CPC 밀치기. 채팅 중 입력 차단.
- 플레이어 HP 100 / CPC HP 200, CPC 공격 20, 방어 중 모든 방향 피해 80% 감소.
- CPC 돌진: 기본 속도 10, .65초, 재사용 6초. 충돌 좀비를 앞쪽으로 이동시키며 종료 후 1초 스턴.
- 밀치기: 반경 3, 거리 3, 재사용 4초, .5초 스턴. 스킬 수치는 CpcSkills 인스펙터에서 조절.
- 일반: HP 100, 공격 10. 기어다니기: HP 50, 공격 10, 기존 이동속도 1.5배.
- 토사물: HP 80, 3초 간격, 중력 포물선 cube, 충돌 피해 20.
- 부머: HP 80, 접근 또는 사망 후 이동을 멈추고 2초 뒤 폭발. 반경은 캡슐 최대 크기의 2배, 피해 50.
- 버로우: 이동하지 않음, 접근 피해 20, 플레이어 이동 5초 봉쇄. CPC가 접근하면 즉시 해체. 미지정 HP는 100, 발동 간격은 5초.
- 점프: HP 80, 재사용 5초, .65초 포물선 도약, 착지 반경 내 피해 30 후 1.5초 도주.

`CombatPrefabs`에 6종 프리팹이 있다. NavMesh 위에 배치하면 플레이어와 CPC를 자동 연결한다. 기존 씬 좀비 종류는 유지했으며, 각 SurvivalZombie의 Kind를 선택하면 종류별 스킬 컴포넌트가 자동으로 붙고 이전 종류의 컴포넌트는 제거된다. Normal은 추가 스킬 컴포넌트가 없다. 같은 종류 전체에 적용할 설정은 CombatPrefabs의 해당 프리팹에서 수정한다. 프리팹 인스턴스에서 별도로 덮어쓴 값은 유지된다. 체력/속도 유형 설정은 시작 시 적용한다.

추가 애니메이션 없이 기존 모델을 재사용한다. `Tools/CPC/Apply Combat Features`는 현재 씬에 전투 수치를 적용한다. 스턴은 이동과 공격을 막고, 속박은 이동만 막는다. 투사체/폭발도 CPC 방어 감소를 거친다.

## 종류별 스킬 스크립트
- SpitterZombieAbility: 토사물 발사 설정
- BoomerZombieAbility: 접근 감지와 폭발 설정
- BurrowerZombieAbility: 덫, 속박, 해체 설정
- JumperZombieAbility: 도약과 도주 설정
- CrawlerZombieAbility: 이동속도 배율 (기본 MoveSpeed는 변경하지 않음)
- ZombieAbility: 공통 대상 탐색과 초기화

예전 ZombieAbilities는 이전 씬/프리팹 설정을 보존하기 위한 호환 데이터로만 남아 있으며 자동 이전 후 제거된다. 종류를 바꾸면 이전 컴포넌트의 개별 설정은 제거되므로 다른 종류의 설정을 유지하려면 각 종류 프리팹을 사용한다.
