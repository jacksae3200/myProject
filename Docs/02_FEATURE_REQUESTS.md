# 02. 추가 기능 요청

마지막 갱신: 2026-11-24

새 기능을 원할 때 이 파일에 작성하세요. 기존 동작의 오류·수정은 [03_BUGS_AND_FIXES.md](03_BUGS_AND_FIXES.md)에 작성합니다. 현재 기능은 [01_IMPLEMENTED.md](01_IMPLEMENTED.md)에서 확인합니다.

## 사용 방법

1. 아래 양식을 복사해 **진행할 요청**에 추가합니다. ID는 기존 최대 번호 다음의 FEAT-번호를 사용합니다.
2. 제목과 원하는 동작만 먼저 적어도 됩니다. 나머지는 에이전트가 기존 코드와 요청을 확인해 보완합니다. 예시 문구나 빈 양식은 작업 지시가 아닙니다.
3. 작업할 때 “2번 파일의 FEAT-002를 진행해줘” 또는 “2번·3번 파일의 대기 항목을 처리해줘”라고 요청합니다.
4. 완료 항목은 삭제하지 않고 **완료한 요청**으로 옮깁니다. 구현 결과는 1번 문서에도 반영합니다.

## 상태와 우선순위

- 상태: 대기 → 진행 중 → 검증 대기 → 완료. 추가 결정이나 외부 조건이 필요하면 보류로 두고 이유와 다음 행동을 기록합니다.
- 구현만 끝났고 필수 검증을 못 했다면 검증 대기로 둡니다. 미실행 검사를 통과로 적지 않습니다.
- 우선순위: P0 진행 불가 / P1 높음 / P2 보통 / P3 낮음. 생략하면 P2로 취급합니다.
- 명시한 사용자 작업 범위가 우선입니다. 일괄 작업에서는 의존성과 우선순위를 따르며, 같은 우선순위라면 진행을 막는 버그를 먼저 처리합니다.
